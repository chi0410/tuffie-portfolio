## 1. 通用規則

| 項目 | 規格 |
|---|---|
| 網址 | `/work-sync-management.html`（專案二、三日後比照 `/work-<slug>.html`） |
| 容器寬度 | **1120px**，左右內距 28px（與首頁完全一致） |
| 視覺語言 | 完全沿用首頁：絲絨暖陶固定背景、噪點、針織紋（18s 爬行）、玻璃材質、字體三件組 |
| Header / Footer | 沿用首頁元件，不另做 |
| i18n | 全頁中英雙語，語言選擇沿用 localStorage 全域記憶 |
| 區塊標題 | **只顯示當前語言**，不做中英疊排 |
