## 1. 專案概述

- **目標**：重建個人作品集網站，回應履歷健檢回饋，強化求職競爭力
- **目標受眾**：招募方（HR、Hiring Manager、設計主管），平均停留時間短
- **範圍**：首頁 + About 頁 + 專案內頁 × 3，中英雙語

### 健檢回饋對照表

| 健檢意見 | 對應解法 |
|---|---|
| Hero 視覺動線 | 一句定位 + CTA 錨點捲動至 Works |
| 加入社群參與、個人學習 | 本版暫緩（列入 Backlog，建議日後補進 About 頁） |
| 加入夥伴回饋 | My Edge 區塊內含 2–3 則推薦語 |
| 加入 AI 能力區塊 | My Edge 區塊內含 2–3 張能力卡 |
| 配色幫助閱讀 | 視覺方向以閱讀對比為第一優先（待定） |
| 專案封面 | 統一風格封面 + 類型標籤 + 角色 + 成果摘要 |
| 閱讀動線 | 內頁固定章節結構 + sticky 目錄／進度條 |
| 深化設計闡述 | 關鍵畫面附設計決策說明 |

## 2. 網站架構（Sitemap）

```
首頁（單頁式）
├── About 頁（完整版經歷）
├── 專案內頁：跨裝置、跨系統的同步管理體驗
├── 專案內頁：官網重構與品牌敘事翻新
├── 專案內頁：機器人多語言互動體驗
└── Resume：外部連結，依語言開對應 PDF（Google Drive）
```

- 首頁 About Me 區塊 = 精簡版；About 頁 = 完整版
- Resume 非網頁，為中英兩份 PDF 直連（需確認 Drive 共用權限為「知道連結者可檢視」）

## 3. Header 規格

### 組成（左到右）

Tuffie（Logo，回首頁頂部）｜Works｜About｜Resume｜My Edge｜語言切換（EN／中）

※ Contact 已從導覽移除，待 Contact 區塊回歸時一併補回

### 各項行為

| 項目 | 行為 |
|---|---|
| Works | 平滑捲動至首頁 Works 區塊 |
| About | 同分頁跳轉至 About 頁 |
| Resume | 新開分頁，依當前語言開對應 PDF |
| My Edge | 平滑捲動至首頁 My Edge 區塊 |
| 語言切換 | 切換全站中英文案 |

### 通用行為

- Sticky：捲動時固定頂端，背景轉實色 + 細底線
- Scroll spy：所在區塊對應導覽項目高亮
- 手機版：收合為漢堡選單
- 專案內頁與 About 頁：額外顯示「← 返回作品」

## 6. 專案內頁模板需求

固定章節結構：

1. **封面區**：類型標籤 + 角色 + 時程 + 一句成果摘要
2. **Overview**：背景脈絡、團隊分工、使用工具
3. **問題定義**：要解什麼問題、限制條件
4. **設計決策**：關鍵畫面 + 為什麼這樣設計、比較過的方案
5. **成果與反思**：量化成果 + 學到什麼
6. **底部導覽**：「下一個專案」卡片

功能需求：桌機 sticky 側邊目錄／手機閱讀進度條；圖片統一寬度 + 圖說；lazy load

---

## 7. 全站通用需求

- **RWD**：手機、平板、桌機
- **i18n 中英雙語**：文案集中於結構化檔案，切換即換資料
- **SEO**：每頁 title、description、OG image、favicon
- **效能**：圖片壓縮 + lazy load
- **無障礙**：alt 文字、文字對比達 WCAG AA
- **內容與程式分離**：專案內容以 JSON 或 Markdown 管理
